PACKAGE MAP (for defense)

✅ Main runtime
- server/            : Game logic (Single Source of Truth), processes client requests
- client/            : Swing UI (FlatLaf) + networking client
- common/            : Message + MessageType (protocol)
- DTO/               : Data Transfer Objects (GameStateDTO, PlayerDTO, TileDTO)
- model/             : Core domain models (Player, etc.)
- tiles/             : Tile types (Property/Go/Jail/Chance/Tax) + structures (Home/Hotel)

✅ Data Structures (manual, no java.util collections)
- dataStructures/hashtable/HashTable          : replaces HashMap for lookups
- dataStructures/stack/Stack                  : Undo/Redo actions
- dataStructures/queue/Queue / BlockingQueue  : server request queue (FIFO)
- dataStructures/heap/MaxHeap + DataAsset     : Top-K report, updateKey implemented
- dataStructures/bst/BinarySearchTree         : insert/delete/inorder (PDF requirement)
- dataStructures/bst/PropertyBST              : properties-by-price report (BST)
- dataStructures/graph/AdjListGraph           : adjacency list weighted graph (PDF requirement)
- dataStructures/tree/AssetTree               : asset reports (Tree requirement in PDF)

⚠️ Legacy UI package (not used in current run)
- Game/              : older menu/splash UI kept for reference only
